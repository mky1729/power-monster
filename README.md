# PowerMonstar

未知のパワモンとリンクし、失われた世界の謎を追うスマートフォン向け冒険RPGです。

## プロトタイプ

- パワモン研究施設を探索
- アンノウンエリアへ移動
- 敵の次の行動を読んで戦うコマンドバトル
- パワーゲージとパワーリンク
- ブラウザへの進行状況保存

プレイ版: https://power-monstar.haruneko70.chatgpt.site

パワモン画像は現在仮シルエットで、正式画像へ差し替え予定です。

## 開発

```bash
npm ci
npm run dev
```

本番用ビルドは `npm run build` で確認できます。
